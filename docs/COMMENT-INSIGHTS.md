# 评论选题入口（3.1.2）

“今日工作台”首屏提供高赞评论、最新解读、全部评论选题三个入口。“选题库 → 评论选题”保存每日解读和由评论产生的候选；原始数据仍保留在“热点早报 → 竞品评论洞察”。

复用既有可编辑IP资料、选题、历史版本与归档。候选默认“待讨论”，不是已完成作品或已核事实。只保存本机私人记录，不调用模型、采集接口或平台发送，也不触发云端同步。

```sh
node scripts/workbench-comment-insights.mjs --root DATA --project PROJECT_ID --file DAILY_INSIGHTS.json
```

输入格式：

```json
{
  "date": "2026-01-01",
  "summary": "首屏摘要",
  "content": "观众在问什么—原话/点赞/作品依据—可怎样切入—需补核什么",
  "sourceUrl": "",
  "candidates": []
}
```

`candidates`最多3项，每项填写`title,audience,question,angle,evidence,sourceUrl,needsVerification`。传入已审阅的隐私安全文本；健康等敏感细节改成明确标注的概述，原件留私有证据。用户侧日期和采集时刻按系统本地时间显示，不伪造历史归纳日期。无新证据不重复旧题，不生成空白日报。

稳定日期和标题标识用于当前IP去重。重试保留人工修改和已归档记录；当天需补充时使用现有编辑入口。未知项目、无写入权限、非法日期和带凭据/非HTTP来源链接会被拒绝。导入后核对首页、正文、编辑保存与候选状态；仅本地文件存在不算工作台可见。

验证：隔离库测试覆盖项目隔离、导入幂等、人工修改/归档保护、默认状态、转义与只读编辑边界。运行`npm run test:ip`。
