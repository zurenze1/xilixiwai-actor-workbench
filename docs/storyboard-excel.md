# 分镜执行台 Excel 导出

在分镜项目顶部点击“导出 Excel 表格”，选择保存位置。进行中的分镜先保存为固定版本；历史版本在“版本与导出”中点击该版的“Excel ↓”，不会改写历史稿。归档项目使用其已有固定版本。

导出为标准 `.xlsx`，包含镜号、时间与时长、口播、画面、花字字幕、转场声音、剪辑备注、素材引用及执行状态。冻结表头与前两列，支持筛选、自动换行和横向打印。空时间保留“待定”，执行状态来自实际记录，导出不会自动勾选完成。

Excel 中的文字可以编辑；外部 Excel 修改不会自动写回工作台。素材栏保留固定版本的标题、文件名与公开出处，不将本机文件路径当作可外发附件。原稿有多少内容就导出多少，不把选题提纲自动写成历史拍摄记录。

实现复用 [ExcelJS 4.4.0](https://github.com/exceljs/exceljs/tree/v4.4.0) 的 MIT 版本，分发包来自 npm 官方注册表；本机浏览器生成，无需联网下载依赖。依赖与许可证在 `practical/modules/creator-workbench/vendor/`，随创作模块构建打包，不新增运行时安装步骤。

验证命令：`node --test practical/tests/execution-xlsx.test.mjs`。覆盖多行中文、逐镜顺序、原话不被解析成公式、毫秒时间、固定素材出处、冻结/筛选/打印配置及缺失载荷报错。真实桌面保存及 WPS 阅读另行验收，不以单元检查代替。
