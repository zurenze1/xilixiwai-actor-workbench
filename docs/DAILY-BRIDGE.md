# 既有每日任务投递到IP工作台

复用现有日报结构与采集规则，不新增自动化、收费模型、平台登录或发布。目标是当前IP的创作目录，不是基础资料数据库，也不是原自媒体工作台目录。

由本机任务配置提供当前IP的绝对目录；命令必须明确带`--data`，缺失则停止，不默写旧库：

```sh
node scripts/workbench-daily.mjs context --data '/本机IP创作目录'
node scripts/workbench-daily.mjs import --data '/本机IP创作目录' --file '/当天实际工作台日报.json'
```

每次先读context中的动态关注名单、网页身份偏好、既有事件和当前编辑目标。新闻来源、原文日期、人物实名、原图、评论的实际观察时间及四栏数量继续按原任务要求核对；原图受限不以生成图冒充，缺口如实记录。JSON先原样保留再导入，相同内容重试返回duplicate，不重复创建日报；修订须合并已有内容并保留历史。评论与活动不因迁移而放宽读取或外发权限。

日报属于创作资料库，在“热点雷达”查看。JSON、原文与原件进入创作资料完整备份。基础IP资料的ZIP单独保留；两份备份共同覆盖这个IP，任何一份都不应单独称作整个工作台的全量备份。

迁移只改既有任务的投递路径，保留任务ID、原聊天、准备/交付时刻、内容范围、通知和暂停状态。手动重放真实日报验证目的地与幂等性，不等于未来定时触发已发生。
