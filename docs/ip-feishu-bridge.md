# IP工作台：共享原件、云端来源与版本留档

复用飞书官方 lark-cli，不建立第二份云端主表。所有者账号保存原件；已获协作权限的CLI账号操作原件。网页协作者权限和CLI OAuth scope是两个独立条件，多维表格高级权限还可能限制新表。

## 本机连接

私人连接文件为用户数据目录的 `feishu/connection.json`，不进入仓库、应用包或公开备份。字段为 `cli`（绝对路径）、`profile`、`baseToken`、`url`、`projects`、`sources` 和 `productionTable`。不保存访问令牌。

- `projects` 以本机项目ID为键，值含name，与远端IP字段一致。
- `sources` 每项含name/type/tableId，可用projects限定适用的项目。未限定时仍按行内IP过滤，空IP是共同参考。
- type支持topics/references/plans/competitors/strategy。云端参考只读，点击后先生成可编辑选题表单，经保存后进入当前IP。
- productionTable指向“制作项目”：名称、IP、类型、版本、状态、归档状态、负责人、逐字稿、画面与执行、关联记录、更新时间、本机记录ID、内容JSON，均为文本字段。

应用启动及每10分钟读取一次，保存后延时同步。仅在工作台运行、网络及授权有效时执行。断网不覆盖上次成功快照，UI显示失败。登录续期由用户正常授权，不承诺永不失效。

原生应用的PATH可能找不到npm包装器所需的Node。优先配置官方CLI包内已核验的本机可执行文件；先在最小PATH环境验版本，再从正式应用进程完成同步，不以终端单次成功代替后台验收。

CLI失败必须读取结构化标准错误，区分权限错误、进程退出与超时；不能直接拼接子进程异常message（可能包含完整命令和私人正文）。保留失败所处阶段及上次成功快照。最终验收须包括桌面应用重启后的自动同步、界面手动同步和云端版本键去重；一次网络超时恢复后，也不能承诺永远不会失效。

## 主源与边界

云端策划/参考资料是策划主源；本机制作记录和分镜固定版本是制作主源，向云端追加快照。不是任意单元格的双向覆盖同步。版本键由项目、记录、版本号组成，分镜使用固定版本ID。重复同步不重复追加，后续改稿不改变已有快照。

共同文件夹可让新增子文档继承协作权限；目录外的旧文档不会自动共享，快捷方式也不能代替目标原件权限。新增文档还须核所有者，不能因进入共同目录就假设所有者已转移。其他人共享的群文档仍由原所有者控制。

## 留档

文案、选题、拍摄准备、任务、复盘等共用记录可“保存并归档”或“归档并新建下一份”。显示及导出采用`MM.DD 标题 Vn`；保留原始标题/日期及来源。分镜归档时创建固定版本，切换档案库可查看，继续修改须显式恢复。新建项目使用新ID，不覆盖上一篇。

机器转写保留原文并标明待校对；当前生成分镜不冒充历史制作过程。执行时长、素材授权和事实判断必须单独核实。归档表示保存，不等于已审核、已拍摄或已发布。

## 验收

运行 `npm run test:ip`，验证IP隔离、断网缓存、重复同步、固定版本和真实HTTP归档/新建；再在最终安装版检查稿件、分镜、档案入口与云端回读。原生界面、实际同步、源码推送和安装包发布分别报告。
