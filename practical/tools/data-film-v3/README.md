# 数据出片 V3.0.0 · 工作台工具箱源码

工资构成、月工时、收入与时薪三种模板；自填数据与来源，自选重点色和工资重点项。复用同一Remotion场景进行Player预览和横竖屏H.264 MP4导出。

这是既有本机“数据出片V2”项目的升级源码副本，不上传个人数据、素材、旧成片、模型、Node依赖或Python环境。保留原工作台入口和本机V2目录；不是GitHub Pages在线后端，也不是新建的独立网站。

## 更新已有本机工具

1. 备份原项目要改的源码、package.json和锁文件，保留V2源码、public、ui/V2/assets、state及outputs。
2. 将本目录中的src、scripts和ui/V3文件覆盖到原“数据出片”项目的对应位置，同步package.json和锁文件。原目录未包含的V1/V2文件不删除。
3. 在原目录运行npm ci，再npm run build:v3及npm run check；沿用原有Python .venv和已有Remotion浏览器。
4. npm run test:v3；从IP工作台工具箱或原独立启动器打开。工作台服务分配的本机端口以实际值为准。

脚本使用环境中的node；如需指定可设DATA_FILM_NODE。后端为本机Python标准库服务，宏观更新仍复用原有V2环境，不复制其历史数据进入公开仓库。界面构建产物ui/V3/app.js由build:v3生成。

## 数据边界

- 空值不当0；时薪分母必须大于0；天数0至31、每日小时0至24。工资项目合计与税后到手收入分开。
- 金额来自使用者填写，必须有来源；不是自动取得个人工资。演示数据不当作本人收入或项目业绩。
- 每次生成新目录保留JSON、CSV、计算结果、日志及视频，旧媒体不覆盖。

## 已验证与限制

本机三模板×两比例实际导出、长标题/5工资项目/自选色边界、15项数据与日历检查、六种版式浏览器文字边界、8份MP4全解码及真实下载。没有在用户正在使用的剪映工程里导入验收。原生App自动启动外部Python有卡住现象，当前经独立启动后由工作台复用；不将独立启动成功当作原生冷启动修复。

代码使用既有[Remotion](https://github.com/remotion-dev/remotion)、React和esbuild，以package-lock.json锁定版本；依赖许可证见各上游项目。本仓库不重复打包第三方依赖或参考视频。
