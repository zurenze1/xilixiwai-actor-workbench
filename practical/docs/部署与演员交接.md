# 本机验收与演员部署交接

更新2026-10-24。账号、密钥、资料和部署资源由演员或团队持有；实战云端尚未部署。

## 两种使用方式

本机：演员在自己的电脑启动服务，即可独立使用，无需先买云服务器。关闭服务后网页不能读写，数据仍留在磁盘。

在线：跨设备或团队长期访问，需云服务器或支持Node.js后台、数据库与持久磁盘的托管账号，以及HTTPS域名。静态空间/GitHub Pages不支持这些实战后台。

代码相同，资料存于各部署自己的数据目录；两个部署不会自动同步。

## 本机启动

安装Node.js24，进入源码目录：

```sh
npm ci --ignore-scripts
npm run start:practical
```

打开 http://127.0.0.1:4930/practical/，注册自己的账号。初始为空，可导入明确标记的虚构《逆光来信》资料。

Mac可双击`practical/启动实战工作台.command`，首次安装锁定依赖。默认不启用任何本机个人模型登录态。使用者安装、登录自己的Codex/Claude Code后，可在终端显式加`--local-tools`。

邮箱目前作为登录名，未接邮件验证/找回邮件；首次注册请妥善保存密码。管理员在设置生成指定邮箱的72小时邀请链接；对方注册后打开链接加入，有编辑/只读权限。私人空间不向其他成员开放，经营管理仅管理员可见。

## 数据与备份

默认目录是源码上一级`runtime-practical/`，不在公开web目录。可用DATA_DIR指定持久磁盘目录，包含身份库、业务库、原件和本机加密主密钥。不要公开上传或丢失该目录的主密钥。

- 影视项目导出ZIP，包含当前账号可见资料和原件；恢复创建新项目，不覆盖旧项目。
- 肉肉、经营在各自模块完整JSON备份/恢复，先校验SHA-256，再重映射原件ID。
- 私人健康可在列表导出CSV，仅本人可见。
- 整服务迁移：先停服务，完整复制数据目录至本人控制的加密备份盘；恢复前保留当前目录副本，再以完整备份目录作为DATA_DIR启动。不要只复制正在写入的单个SQLite文件。此备份含账号与凭据加密材料，不能作为公开项目包分享。

金额用整数分，各币种分别统计，不自动换汇。税务进度需会计确认、日期和缴纳凭证；软件不向电子税务局申报或替会计定税率。

## 在线HTTPS部署（演员决定后）

准备支持Docker Compose的服务器、指向它的域名和开放80/443端口；定期备份持久卷。密钥不写入GitHub或网页。

```sh
cp practical/deploy/.env.example practical/deploy/.env
```

编辑WORKBENCH_DOMAIN为团队域名，然后：

```sh
docker compose --env-file practical/deploy/.env -f practical/deploy/compose.yaml up -d --build
```

Caddy提供HTTPS，后台4930仅在容器内网；账号/资料在workbench-data持久卷。不要删除持久卷。上线后管理员本人注册、邀请成员并配置测试自己的模型。在线容器禁止本机CLI连接。

本轮Mac没有Docker运行时，**未构建镜像、未验DNS/证书/托管账号**。这是一套待部署方实际验证的配方，不能写成云端已部署。托管平台必须支持持久磁盘，否则重启可能丢资料。

环境变量：PORT默认4930、DATA_DIR、PUBLIC_URL、PRACTICAL_MODE=online。在线PUBLIC_URL必须HTTPS；本机用127.0.0.1且与网页地址完全匹配。主密钥首次随机生成，文件权限600；如改用PRACTICAL_SECRET环境变量，应同样备份并保持不变。

## 演员验收顺序

1. 注册本人账号，确认“本机版”，新建项目、填导演和团队，刷新回读。
2. 导入虚构原文、拆场；配置自己的模型，选择原文、确认调用次数，核对真实结果和引用。
3. 记表演笔记、生成镜头建议JSON，在分镜导入、上传参考图、调整并导出HTML离线预览。
4. 录入留言、会议、任务和授权，回复先审核，外发后人工补链接。
5. 经营新增虚构主体、分期收款、资产/品牌库存，核对凭证；邀请只读成员验证隔离。
6. 肉肉原照片、表情PNG、含原件备份恢复；确认私人健康与经营不进入普通项目导出。
7. 停服务再启动，确认原数据回读。在线部署另验HTTPS、跨设备协作和服务器备份。
