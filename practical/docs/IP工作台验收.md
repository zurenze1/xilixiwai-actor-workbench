## 正式运行与边界

正式服务已用`npm run start:ip`启动于 <http://127.0.0.1:4936/practical/ip/>，健康接口确认`profile=ip`、`ipVersion=1.0.0`。首次启动时正式数据库的项目、记录和附件均为0，未复制测试账号或虚构IP。使用者自行注册并创建自己的IP。当前进程的持续存活不等于系统服务或开机启动；之后可双击根目录启动器运行，关闭其服务窗口后停止。

浏览器验收不等于用户审美或真实业务流程已验收。实体手机、跨电脑/团队部署未验证。本版平台发布和数据来自人工登记/CSV导入，没有自动发帖、自动抓取热点或真实AI调用。附件上限、备份范围与公开方法出处见[IP工作台说明](IP工作台.md)。
