# 图解使用说明维护

此说明页由演示版与实战版共享。它帮助第一次使用的人找到板块、理解填写和保存方式，并区分虚构示例与使用自己的资料。页面包含八阶段地图、分类与搜索、四步操作图卡、真实表单字段，以及主题、折叠、备份、人工复核提示。

## 生成与更新

```sh
node scripts/build-usage-guide.mjs
```

脚本以当前仓库的实际代码为准，提取：

- `web/app.js` 的 PAGES、PAGE_NAME 与缺省名称。
- `web/data.js` 的八个 stations。
- `practical/web/app.js` 的 NAV。
- `practical/web/forms.js` 的 ActorForms.MOD，包括字段名称、类型、必填和选项。

目录写到 `web/guide/catalog.json`，所有实际 NAV 都会收录。若新增板块没有精细说明，先生成带真实名称、实际字段的基础操作卡，并标记“待补详细说明”。请在 `web/guide/content.mjs` 补写该板块的四步操作和输出边界，再生成目录。生成脚本只能为新入口列出基础信息，不会自动写出完整的人类使用说明。

生成时递归登记 `web/` 与 `practical/web/` 中的 `.js/.mjs/.html/.css` 源文件，覆盖各前端模块和样式。排除 assets、vendor、node_modules、scripts、qa、隐藏目录、*-artifacts 与 JSON 输出，不读取后台、密钥、用户资料或本机运行目录。仓库代码是可信输入；脚本只在隔离 VM 中求值本仓库的定义，不执行远端脚本。

`sourceHash` 由路径和各源码 SHA256 得到，`contentHash` 另包含人工图卡内容。两者均未变化时，`generatedAt` 和生成文件字节保持不变，不会因重复启动制造时间戳差异。新增前端文件或修改已有模块后应重新生成；若忘记生成，浏览器校验已有登记文件时会将不一致标黄。新增、但尚未登记且未被已登记代码引用的独立文件无法由浏览器发现，CI 必须重跑生成并检查差异。

## 运行与同源协议

实战后台从 `/demo/guide/` 提供共享说明，不需要复制到 practical。独立页面可加查询：

- `mode=demo` 或 `mode=practical`
- `embedded=1`：嵌入模式，说明版本跟随父工作台
- `theme=tide`、`theme=butter`、`theme=moss`

同源嵌入打开实际板块：

```js
// 演示版，page 取实际 PAGES 或 0–7 阶段编号
parent.postMessage({type:'actor:guide-open',page:1},location.origin);
// 实战版，route 取实际 NAV key
parent.postMessage({type:'actor:guide-open',route:'script'},location.origin);
```

父壳必须同时校验 `event.origin`、`event.source` 和允许的 page/route，再执行自身导航。说明页也只接收同源父页面的 `actor:theme`（兼容 workbench:theme/theme）主题消息；主题值限三种。嵌入的打开按钮与板块备用链接都通过父壳切换，不创建新标签页。独立访问使用真实链接；静态演示站不存在实战服务时明确提示未连接，并将“对应演示”链接标明。

演示示例不会分析用户上传资料。说明页明确提供进入实战版的入口；真实模型连接由使用者自行配置，未连接模型仍可保存、编辑和导出手工业务记录。

## 同步标记的含义

页面逐一请求登记源码并计算 SHA256：全部匹配才显示“功能目录与字段已同步”。有可读源码不匹配显示“页面已有变化 · 说明待更新”；只核对到演示源码时标明“实战待连接”。同步标记说明目录和字段对应所登记源码，不意味着每张人工图卡已经经过人工复核，也不代表后台、模型账号或外部服务已验收。

前端源地址自动映射：`web/` → `../`；`practical/web/` → `../../practical/`。服务器需正确返回源码和 MIME；不可把不存在的 JS 请求统一返回 HTML 首页。

## 文案边界

- 演示肉肉生活包含照片原件与完整备份；表情工坊仅写在实战宠物模块。
- 公司与品牌管理中的纳税是期间、期限、会计确认及缴纳凭证记录，不是自动报税。
- 规则拆解不是 AI 结论；原文匹配不代表推断正确。版权、舞蹈安全和重要对外操作仍由相应人员审核。
- CSV/Markdown 主要用于文字交换；完整备份与原件按各板块真实导出能力说明。
