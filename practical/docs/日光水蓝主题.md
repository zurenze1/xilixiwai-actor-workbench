# 日光水蓝 · 实战工作台主题

2026-10-24。祖老大提供水面、阳光与手的网页截图，明确选择蓝色。主题使用原有`tide`键，其他主题保留。原参考截图没有复制到源码或部署包。

## 页面处理

- 登录：水面摄影与白色轻字占主要视觉，右侧独立清楚的登录表单；手机变为上图下表单。
- 首页：阳光水面横幅、深水蓝文字区、白色标题与玻璃质感导出按钮，下面为白色工作面板。
- 编辑页：缩短水面横幅，正文保持高对比；导航、控件、表格、状态和留白统一。
- 分镜/经营/肉肉：共享蓝色变量和水面章节标题，保留各自完整操作。
- URL `?theme=tide`可一次切入新蓝色；消费参数后移除，之后用户手动切换主题及刷新会保持选择。

色板：背景`#F0F6FA`、正文`#153C54`、辅助文字`#5C7789`、主色`#23668C`、浅水蓝`#E5F1F8`、线框`#D7E5ED`、面板白色。只在`tide`作用域内使用。

代码：`practical/web/themes/tide.css`；图像：`practical/web/assets/tide-sunlight-v1.png`，1774×887，2166493字节。使用**内置imagegen**生成，以用户截图为视觉参考，创作新的无字摄影背景；未调用API密钥或下载参考站原片。

GitHub先检索了liquid-ripple、liquid-glass等水波/折射方案。当前主题基于已有CSS实现，不新增渲染依赖，没有复制这些仓库代码；不把检索到的新小仓库当成已验证成熟组件。
