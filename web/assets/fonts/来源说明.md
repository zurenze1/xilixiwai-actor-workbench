# 英文标题字体：Outfit

核验日期：2026-10-24。

## 参考与选择

项目提供的 [Instagram 参考](https://www.instagram.com/p/Dee7-GwG-kj/) 是 Kindred Studios 的 Wildwood Sans。已查看图片及 [Kindred 官方字体页](https://kindredstudios.us/fonts/wildwood-sans)：它是粗壮、带手绘不规则的无衬线字体，不是细衬线或宋体。官方页面列出付费商业许可、无限网页流量，1–10 员工档为 29 美元，并提供桌面 OTF／网页 WOFF2；此次没有购买、提取或部署该字体，完整许可条款未取得。

本项目选择 **Outfit** 作为几何粗无衬线的开放近似。它更规整，没有 Wildwood 的手绘轮廓；不声称与原字体相同，也没有混用其他作者的同名 Wildwood。中文建议保留系统粗黑体与充足留白，Outfit 不作为中文字体使用。

## 公开来源与许可

- [Outfit 官方 GitHub 仓库](https://github.com/Outfitio/Outfit-Fonts)，原作者仓库已归档；字体亦由 [Google Fonts 官方镜像](https://github.com/google/fonts/tree/main/ofl/outfit) 收录。
- [官方原始许可证](https://raw.githubusercontent.com/Outfitio/Outfit-Fonts/main/OFL.txt)：**SIL Open Font License 1.1**，Copyright 2021 The Outfit Project Authors。
- 原样保留 `LICENSE-Outfit.txt`；未修改、转换或子集化字体。可以按 OFL 随软件嵌入与再分发，需保留版权和许可证，不可单独售卖字体本身。完整条件以附带许可证为准。
- 字体文件直接来自官方仓库 `fonts/webfonts`。下载字节同时验证了 GitHub blob SHA-1，未使用第三方转载下载站。
