# 七个指定官网的摄影参考

历史阶段仅做本机设计验收；2026-10-24已按祖老大“新更新的所有东西都在GitHub上更新”的明确要求纳入当前公开源码版本。所有照片统一标注“第三方品牌视觉参考，非演员本人／代言”，不能当作演员本人、代言、剧组、影展、公益项目或实际资产。

实际访问了七个指定页面：Contiki、Showpo、Rachel Gilbert 可匿名读取并下载；Calvin Klein 与 Veronica Beard 普通浏览器仍403，Perigold返回429；Belvedere普通浏览器出现年龄确认墙，本轮未填写年龄且未提取墙后摄影素材。原图保留在仓库外的本地验证目录，不删除已有素材。

从19张候选中实际查看联系表，剔除文字海报1张、同画面裁切1张、近似姿势的颜色变体1张，最终16张：Contiki 6、Showpo 5、Rachel Gilbert 5。各文件为独立画面，不用同一照片多裁切凑数。素材数量超过单源原定2–4张，是因为四个指定来源不可用；没有冒称拿到了全部七源图片。

只等比缩小至最长边1920px，转WebP quality90；不改色、不裁切、不去水印、不重画。原图URL、尺寸、字节与SHA-256、派生SHA-256逐张见manifest.json。竖版服装参考建议放完整竖图卡片，不强行裁成横幅；横图适合页头或场景板。去向为设计建议，由主工程统一接入，蓝色主题、肉肉皮肤与原有照片均不在此任务中更改。
