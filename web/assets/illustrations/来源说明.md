## 来源与处理

- 使用 Codex 内置 `image_gen` 生成；不是下载的第三方图库，也不是用户私人照片。
- 首次生成后，仅通过内置生成工具修正九格主体留白。两次原始输出均保留在 Codex 默认生成目录，未覆盖。
- `actor-story-atlas-v1.png` 是最终生成原图的逐字节副本，1254 × 1254 像素，RGB、不透明；该副本已移至仓库外的本地验证目录，不随网页发布。

- 参考原件保留在本地验证目录，发布仅含新生成图。未删除任何原始素材。
- 内容为通用工作物件和白色马尔济斯犬插画，不代表任何真实演员、工作室、财务记录或真实宠物肖像。

## 轻量动效的公开视觉参考

祖老大提供了以下公开组件页面作为动感方向，已于 2026-10-24 查看公开说明：

- [React Bits Pro · Rising Lines](https://pro.reactbits.dev/docs/components/rising-lines)：从发光地平线向上运动的光线。
- [React Bits Pro · Elastic Lettering](https://pro.reactbits.dev/docs/components/elastic-lettering)：可轻拖、回弹的标题。
- [React Bits Pro · Blinking Dots](https://pro.reactbits.dev/docs/components/blinking-dots)：两层点阵缓慢明暗变化、轻微漂移。

项目新增的 `web/scene-art.js` 与 `web/scene-art.css` 使用原生 Canvas、DOM 和自写弹簧计算独立实现简化动效，没有访问或复制 React Bits Pro 付费源码，没有引入 React、WebGL 或新依赖，也不宣称获得 Pro 组件授权或逐像素还原其效果。仅取公开视觉方向：蓝色光线、轻微文字弹性、低亮度缓慢点阵。主题为水蓝、暖金、浅绿，不使用参考中的紫色。

挂载约定：

- `[data-illustration="script|performance|previs|studio|fans|rights|business|life|pet"]`：插画；`SPAN` 或 `[data-illustration-slot]` 作为独立图像槽，不增加 hero 留白。槽可用已有 CSS 设置大小，或设置 `--scene-art-slot-size`。
- `[data-rising-lines]`：上升光线背景。
- `[data-blinking-dots]`：慢速点阵背景，仅在明确选择的简报、运营页头使用；不代表联网或数据实时状态。
- `[data-elastic]`：少量主标题的轻拖回弹，保留原始 DOM 文本、换行和可访问名称。未标注的业务文字不处理。
- `window.ActorSceneArt.refresh()`：显式重新扫描；DOM 新增、主题变化会自动更新。
- `pause()`、`resume()`、`toggle()`：暂停、恢复、切换全部装饰动效；偏好只保存在本机 `xilixiwai.scene-art.motion.v1`，不上传。
- `status()` 返回运行状态；`destroy()` 移除装饰并恢复标题文本。

光线与点阵共用最高 30 fps 的一个动画调度，离屏、页面隐藏或元素移除后停止。系统“减少动态效果”优先，显示静态画面。所有 Canvas 和插画均穿透鼠标事件，不阻拦业务按钮；触屏标题允许正常竖向滚动。没有采集业务内容、鼠标轨迹或网络遥测。

## 轻尘鼠标尾迹

新增公开方向参考：[React Bits Pro · Stardust Cursor](https://pro.reactbits.dev/docs/components/stardust-cursor)，2026-10-24 查看公开说明。本项目仅独立实现轻微细尘，不含该 Pro 组件源码、流体模拟或点击爆团。

- 只在 `body[data-stardust-cursor]` 明确启用，并且系统为细指针鼠标时运行；不替换原指针。
- 颗粒直径 1.1–2 像素，尾迹横向厚度约 12 像素，最多 14 颗，450 毫秒内消散，最大透明度 0.2。
- 没有自动播放、点击爆团或静止时的动画；与光线、点阵、标题共用已有最高 30 fps 调度及暂停偏好。最后一颗消失后不保留动画帧循环。
- 输入框、文本域、选择框、可编辑内容、`.script`、`[data-script-reading]`、`[data-stardust-exclude]` 区域不产生细尘；聚焦输入时全页停发。阅读区域需要在容器标注上述类名或属性。
- 触屏、系统减少动态效果时完全关闭；页面隐藏、暂停、滚动、窗口尺寸改变会清空已有细尘。Canvas 固定定位但 `pointer-events:none`，不拦截任何业务点击。
- 粒子坐标只在不足半秒的绘制缓冲内使用，不持久保存、不发送网络、不记录鼠标轨迹。
