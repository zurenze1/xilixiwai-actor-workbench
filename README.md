# 戏里戏外 · 演员与工作室独立演示

[打开在线演示](https://zurenze1.github.io/xilixiwai-actor-workbench/) · [交互发布会](https://zurenze1.github.io/xilixiwai-actor-workbench/launch.html) · [演示使用说明](docs/演示版使用说明.md)

这是独立的演员与工作室交互演示：八阶段路线、20板块、资料编辑、造型与分镜预演、经营与账号运营演练、肉肉模块及分层导出。示例人物、团队、项目与分析均为虚构。

**本仓库与祖仁泽的本机IP工作台分开维护。** 当前分支已移出IP专用模块、后台、桌面启动器和资料桥接脚本；原提交历史保留。现用IP完整工程、数据库、素材和账号配置不在本次发布范围。

## 直接使用

打开在线演示即可。填写的演示资料保存在当前浏览器；主线、肉肉、经营/运营、资料分析和预演按各自入口备份，主线导出不包含全部独立模块。重要内容请主动导出。

这是演示，不提供账号后台、模型调用、自动发帖或平台登录。无需输入密码或API密钥。公开演示与本机预览行为一致。

## 本机预览

安装Node.js 24.21或更新版本，在本目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4890/ 。端口可通过PORT环境变量指定。预览服务只读取web静态文件，不连接IP工作台或私人数据库；运行现成演示不需要安装依赖。

## 文件与重建

- web/：实际发布的演示、媒体与交互模块。
- src/、demo-source/：演示自身的规则及可重建模块源码。
- scripts/：演示构建、指南生成和静态预览。
- tests/：演示自动检查，使用虚构或合成资料。
- docs/licenses/：第三方组件许可证。

```sh
npm ci --ignore-scripts
npm test
npm run build
```

CI检查演示和已提交资源一致；Pages只发布web。本工程无需其他工作台的源码或数据。
