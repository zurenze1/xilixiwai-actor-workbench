# 戏里戏外 · 演员与工作室工作台

同一套代码包含可实际保存资料、连接使用者自己模型的**实战版**，以及独立的**演示版/发布会**。验收材料均为虚构，不代表真实演员、团队、品牌的经历或背书。

## 先用本机版

需要 **Node.js 24 或更新版本**。在源码目录运行：

```sh
npm ci --ignore-scripts
npm run start:practical
```

打开 <http://127.0.0.1:4930/practical/>，自行注册账号。初始资料为空；可以明确导入虚构《逆光来信》原文验收，不预置分析结果。Mac也可双击`practical/启动实战工作台.command`。

本机版可以在演员自己的电脑直接使用。**跨设备、团队在线访问才需要云服务器或支持后台与持久存储的全栈托管账号，以及HTTPS域名。** [GitHub Pages](https://zurenze1.github.io/xilixiwai-actor-workbench/) 继续作为静态演示，不能运行实战账号、私密资料库与模型后台。设置页、登录页均有提示。

## 自己连接模型

设置支持DeepSeek、OpenAI、Anthropic及公开HTTPS的OpenAI兼容文本API。填写使用者账号实际可用的模型ID和密钥；服务端加密保存，浏览器不回传密钥，项目/模块导出不含密钥。共享连接仅共享调用能力。分析前显示所选文字量及调用次数，由使用者确认，服务商可能收费。

使用者在自己的电脑安装并登录Codex / Claude Code后，可显式启动：

```sh
npm run start:practical -- --local-tools
```

仅本机部署的首位注册主人可用，不共享给团队，在线模式禁止；输入走stdin，不经shell执行，禁用工具执行/MCP。实际CLI版本与账号权限需本人点击测试确认。本轮未使用开发者个人账号或真实付费调用。ChatGPT网页登录不等于API密钥。

## 本机体验与视觉更新（2026-10-24）

演示首页提供《逆光来信》八个可实际操作的体验任务。修改权重、选择表演处理、编辑任务、保存回复与审核快照、填写个人批注后，才能完成对应任务；成果单导出实际保存的选择，不用预置结果代替用户操作。会议纪要可按行拆成待办，先编辑、确认再加入看板，保留原话，不自动猜负责人或截止时间。

完整能力目录还提供独立“资料实验室”：18类实战表单字段加7类经营/运营演示表单，可填写、编辑、CSV导入导出、保存附件原件与独立JSON备份。主线备份不包含实验室，实验室使用自身备份。未来5项能力明确标记规划预览，不冒充已生成的视频、全球发行数据或已连接平台。

登录页采用新的彩色人物拼贴背景，首要入口是无需账号的独立演示版；工作台保留原深蓝潮汐、奶油与山野主题，未采用棕色覆盖。肉肉保留原狗狗照片、照护细节与原始相册，增加可选环绕浏览。光线、重点标题、光环、造型揭图/两图对比、作品轮播和稿件结构示意均为原生独立实现，参考React Bits Pro的交互描述，未复制其付费源码。动效支持暂停或系统减少动态；窄幅星尘避开编辑区。

标题英文与数字可使用本地Outfit（SIL OFL 1.1），仅作为用户提供Wildwood Sans参考的开放近似，未购买或冒用原字体。生成图片、公开参考与字库许可见web/assets各来源说明。当前更新首先供本机验收；云端后台、真实模型账号和实体手机需在对应环境验收。


## 可编辑体验与摄影更新（2026-10-24）

演示的17个业务页提供“编辑本页资料”和独立导出。文本、数量、角色说明、分镜时长、工作日历和示例结论均可按当前结构修改；保存后重绘对应页面、图表及统计，刷新和完整JSON备份保留。结构编号、资源路径、颜色配置等系统项保持固定，原示例保留为基线。编辑的示例分析是人工改稿，不冒充模型已基于新输入重算。

发展雷达由演员与工作室自行填写8个维度、当前/目标评分、周期、共同设定者、复盘日期、依据和行动。空值不补零，可设降低或维持目标；分数标记为团队自评。演示目标保存在主线备份中；实战版“发展规划”按项目保存为阶段规划记录，默认仅本人，可选团队可见，支持版本与导出。目标不会自动替团队作职业取舍。

日程可编辑并重新计算冲突；新增作品可修改/删除并更新轮播和题材数量；饮食记录带日期且可更正估算，更新当前日KPI和近7天图。任务看板与内容日历分别维护，任务不会自动排入日历。空白小传不再回填，清空日程不再留下示例通告，下月邀约不计入本月。

工作区水彩图集换为原创虚构人物及工作场景的摄影图集，身体页使用新蓝金水下时尚概念图；原蓝/奶油/山野主题和肉肉皮肤保留。顶部“试试交互效果”可直接进入揭图、两图滑杆、作品轮播、稿件任务、宠物环绕与金属光环，并显示动态是否被暂停/系统减少动态。摄影概念不是演员真实肖像或实际身体状态记录。
