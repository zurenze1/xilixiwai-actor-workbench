# IP工作台 · 本机 Mac 应用

保留现有 IP 工作台，在独立 Mac 窗口中使用。双击应用自动启动本机服务；内置 Node.js，正常使用无需打开终端或开发工程。

## 本机使用

- 应用：安装到当前用户的“应用程序”，桌面放一个入口。
- 数据：`~/Library/Application Support/IP工作台`，与应用分开保存。
- 日志：`~/Library/Logs/IP工作台/service.log`。
- 菜单“查看 → 打开资料文件夹”可直接找到数据。“重新载入”会检查并恢复本机服务。
- 退出应用会停止它自己启动的服务；如果复用的是已在运行的开发服务，退出应用不结束那个服务。
- 支持原生文件选择、保存文件和常用编辑快捷键。外部网页在系统浏览器打开。

迁移时先关闭所有写入者并备份，逐文件核对哈希与 SQLite 完整性，原 `runtime-ip` 路径保留为指向新位置的兼容链接。迁移脚本和个人备份仅保留本机，不进入公开仓库。不要手动用旧备份覆盖已经产生新记录的数据。

## 构建

在 macOS 使用兼容的 Swift 编译器和 SDK，以及带完整 LICENSE 的官方 Node.js 24.21+ 发行包。当前本机版验证范围为 Apple Silicon；最低系统版本为 macOS 13.5，未验证其他 Mac。

```sh
npm ci
# 有热点雷达、分镜执行台源码时先生成其前端资源
npm run build:creator-modules
python3 desktop/ip/build_macos.py --node-root /path/to/official-node --output /path/to/new-build
```

默认 SDK 与编译器版本不匹配时，使用 `--sdk /path/to/compatible/MacOSX.sdk`，不修改系统默认开发工具。输出路径应为新的目录。脚本按白名单复制服务源码及已构建模块，安装锁定的生产依赖，检查模块导入，生成 ICNS，编译原生窗口并验证本机临时签名。

应用不包含运行数据库、密钥、环境配置或个人原件。新版本业务源码更新后，应重新构建并替换应用，数据目录继续复用。本机临时签名不等于 Apple Developer ID 签名或公证；本仓库尚无面向其他电脑发布的安装包。

图标原图及生成来源保存在 `assets/`；Node 和依赖许可随应用保留。
